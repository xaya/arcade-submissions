# Security Policy

This repository holds game submission requests, which are public by design.
Do not put secrets, keys or vulnerability details in a submission issue.

## Reporting a vulnerability

Please do not open a public issue for a security bug. Report it privately
through GitHub's private vulnerability reporting ("Report a vulnerability"
under the repository's *Security* tab), on the repository the bug is in:

- **The arcade platform** (the referee GSP, the rules sandbox, the client SDK,
  and the game hosting and submission services): follow the
  [arcade-platform security policy](https://github.com/xaya/arcade-platform/blob/master/SECURITY.md).
- **A game** (its rules, frontend or tests): that game's own repository.
- **The `ArcadeWager` contract**: [arcade-wager](https://github.com/xaya/arcade-wager).
- **The relay server**: [xaya-relay](https://github.com/xaya/xaya-relay).
- **This repository's issue forms**: this repository.
